# YuriLink

Link-in-bio / media kit for **Yury** — TikTok Shop, YouTube (YC Noticias), Amazon, courses, and featured videos. Built with **Next.js**.

## Run locally

```bash
npm install
npm run dev
```

Open: [http://localhost:3000](http://localhost:3000)

## Scripts

- `npm run dev` — development server
- `npm run build` / `npm start` — production
- `npm run pdf` — regenerate media kit PDF

## Features

- Hero with socials (YouTube, Facebook, TikTok, Instagram)
- YouTube, Courses, Amazon, and featured videos sections
- ES / EN language switcher
- Downloadable media kit PDF
